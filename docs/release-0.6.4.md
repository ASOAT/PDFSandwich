# PDFSandwich 0.6.4

改进文献库删除与分类操作。

- **可选择删除 PDF**：移出文献库的确认框新增“同时删除 PDF”，每次默认勾选。将库内 PDF 及已登记的中文译文移至系统回收站；取消勾选则仅移除文献库记录。初始导入文件、Markdown 笔记、附件及备份保留。尚未复制入库的旧记录只移除记录。
- **处理正在阅读的文献**：先保存笔记编辑状态并保留批注草稿，再停止翻译和等待正在执行的译文保存，关闭该 PDF 后删除，避免译文重新生成。文件删除失败时保留文献记录并说明原因，可重试。
- **快捷创建子分类**：每个分类右侧增加文件夹加号，点击即在该分类下创建，不必先切换当前分类。
- **折叠分类菜单**：右键“移至分类”按层级展开，子分类默认收起；支持返回上级、移入父分类、批量移动和方向键操作。长菜单可滚动，侧栏分类区独立滚动，避免覆盖标签和存储入口。

在软件设置中检查更新，或下载 `PDFSandwich-Setup-0.6.4.exe`（Windows 10 / 11 x64）。支持增量更新；本次无需更新翻译或公式模型，已有 Obsidian Companion 可继续使用。
