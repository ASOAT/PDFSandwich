# PDFSandwich 0.6.3

改进复杂公式识别、修复正文中的公式拆分，并调整图片摘录与资源占用。

- **公式自动识别**：框选完成即在本机识别，无需再点击按钮。更换为 PP-FormulaNet_plus-L，保留整个矩阵和多行分式输入；从原始 PDF 生成清晰截图，结果可编辑、预览和复制。首次另行下载约 701 MiB，校验后缓存，离线使用。小字、下标和复杂标签仍可能识别错误，请对照原图核对。
- **修复公式被当作正文翻译**：例如带帽的 `NOθ`，保留算子、帽号和下标为一组，避免 `NO` 被误译、帽号与正文分离。补充神经算子和离散化相关术语，并兼容术语在 PDF 行尾断开。旧译文请点击“重译本页”。
- **修复标题断词与作者误译**：重新拼合被排版检测切在单词中间的标题，避免 `Hamiltonian` 分成两段翻译；识别论文标题与摘要之间带机构上标的作者行，保留姓名、重音和上标原貌。
- **修复正文与引用括号**：作者—年份引用、跨栏续接的引用及其括号和句号原样保留，兼容括号、作者、年份属于不同颜色片段的情况；普通括号中的说明仍会翻译，括号边界由程序保留。
- **截图到剪贴板**：框选图片后复制到系统剪贴板，不立即生成笔记或附件。可粘贴到 PDFSandwich 的实时编辑／源码视图，也可直接粘贴到 Obsidian；粘贴后才保存附件和插入图片链接。
- **沿用 Obsidian 图片规则**：读取 Vault 原生附件目录；启用 Paste image rename 时，兼容文件名、目录、首标题、YAML 属性、常用日期时间模板与重复编号。不会运行其他 Obsidian 插件或复刻其弹窗。在 Obsidian 中粘贴时仍由 Obsidian 和原插件处理。
- **轻量化**：笔记编辑器和公式预览按需加载；翻译闲置五分钟后释放后台模型；移除未使用的科学计算组件与重复打包的前端依赖。公式模型只在需要时下载，不增加安装包中的模型体积。

在软件设置中检查更新，或下载 `PDFSandwich-Setup-0.6.3.exe`（Windows 10 / 11 x64）。已有 Companion 0.6.2 可继续使用；本次图片命名兼容由 PDFSandwich 完成，不需要修改 Vault 插件。支持增量更新，无法差分时自动回退完整包。

安装包未签名。对应源码、依赖源码、校验文件和可选 Companion 插件随 Release 提供。未自动升级用户正在运行的软件。
