# PDFSandwich 0.4.1

修复含公式的双栏论文中，长段落标记落到其他段落、公式漏标的问题。

- 标记先定位完整段落，再对应内部词句；公式之间的短词和段末标点不再单独匹配到整页各处。
- 根据公式占位符对应行内公式；独立公式及编号在保留的公式区域内匹配，支持双向标记。
- 兼容 PDF 字体提取出的不可见控制字符，减少有译文却无法找到对应位置的问题。
- 重新打开文档时自动重算旧版自动映射，保留用户手动校正；无需重新翻译已有页面。

0.4.0 用户可在“翻译与应用设置 → 软件更新”检查、下载并重启安装。增量可用时只下载变化部分；缺少旧安装包缓存时自动下载完整包。0.3.x 及更早版本需手动安装一次。

下载 `PDFSandwich-Setup-0.4.1.exe`（Windows 10 / 11 x64）。源码及依赖对应源代码见 `PDFSandwich-0.4.1-source.zip`；校验值见 `SHA256SUMS.txt`。`latest.yml` 和 `.exe.blockmap` 供软件更新使用。

本次用实际问题页的本地副本核对，并增加双栏公式、重复连接词及段末标点的回归测试。自动词句对应仍可能存在误差，可手动校正。测试详情见仓库 `docs/verification.md`。
