# 验收记录

2026-09-29，在 Windows 11、约 32 GiB RAM 的本机进行。翻译使用 CPU int8，未依赖 NVIDIA GPU。

## 已完成的实测

- Node 核心测试（3 项通过）：范围读取边界、翻译缓存身份、密钥不参与缓存键、服务地址校验。
- Python 文件测试（7 项通过）：四类原生批注保存、中文内容往返、保留非托管批注、删除标记、外部修改拒绝覆盖、失败时原文件不变、短语/整段映射、搜索和提取。
- 真实 Electron 界面：打开、选择原文并高亮、保存到原 PDF、重开、设置、跳页、双向同步滚动。
- 本地真实翻译：生成可选中文字的中文 PDF，检查公式 `E = mc²` 和矢量图；浅/深色截图人工检查。
- 断网验证：语言/排版模型及字体已下载后，测试进程阻断外网连接；成功输出中文页，记录外网连接尝试为 0。
- 双向编辑：英文高亮、中文下划线、中文手绘、中文便笺，映射到另一侧；便笺文字原样保存；删除与撤销；写回原文件后重开，两侧几何存在，译文缓存保留。
- 本地模型匹配实测包括整段回退和短语匹配两种情况。没有将 attention 对齐当作语义正确率保证。

## 大文件样本

自制 1000 页、95.17 MiB PDF，每页包含不同图像。测试打开后跳到 998 页，当前只创建 5 个画布。
本次启动至文本就绪测得约 370–391 ms；该数字来自同机合成样本，不作为性能承诺。
当时 Electron 各进程工作集合计约 589 MiB（不包含独立 Python 后端），渲染器工作集约 272 MiB。
测试无前端错误，右侧滚动也能驱动左侧。没有把该结果外推到任意复杂或扫描教材。

原始测试报告、截图和测试 PDF 位于本机忽略目录 `test-results/` 与 `tmp/pdfs/`。
可重现入口：`scripts/smoke.mjs`、`scripts/translation-smoke.mjs`、`scripts/bidirectional-smoke.mjs`、`scripts/offline-check.py`。

## 当前已知限制

小型 Argos 模型在术语、残缺词、复杂图注上可能译得不准；检测到异常膨胀或字幕格式乱码时保留原片段。
复杂版面、跨页上下文、扫描件、加密/签名文件不属于完整验收覆盖。尚未收到用户的真实教材样本。
批注写回时生成备份会增加磁盘用量，当前不自动清理用户的备份文件。

独立 PyInstaller 后端已完成真实页翻译（包含排版和字体子进程）。打包脚本显式处理 bitstring 动态模块、Hyperscan DLL 搜索目录和 tiktoken 命名空间插件。
