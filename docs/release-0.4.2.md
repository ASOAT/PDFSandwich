# PDFSandwich 0.4.2

修复重复名称的双向标记，以及公式、编号列表和双栏参考文献的排版问题。

- 正文段落优先拥有内部词句，表头、图注中的同名词不再额外标记正文后面的另一处；段内单独选择重复名称时按出现位置对应。
- 将分离的重音符号、上下标、分子分母和大括号重新组合为完整公式单元，移动与缩放时保留原字形和相对位置。
- 将连续编号列表拆成独立条目，固定编号；保留斜体短语，并修正冠词被当作字母保留、样式占位符外多出括号的问题。
- 修复窄栏间距下漏识别右栏参考文献编号的问题；条目独立排列，保留编号、悬挂缩进、作者和期刊样式。
- 修正列表拆分后的文字层顺序，避免外观正确但无法选择或同步批注。

**更新后重新打开文档，已有自动标记会重新校正，手动校正保留。公式、列表和参考文献的旧译文需要点击“重译本页”才能更新版式；不必重译整本。**

0.4.0 / 0.4.1 用户可在“翻译与应用设置 → 软件更新”检查、下载并重启安装。增量可用时只下载变化部分；缺少旧安装包缓存时自动下载完整包。0.3.x 及更早版本需手动安装一次。

下载 `PDFSandwich-Setup-0.4.2.exe`（Windows 10 / 11 x64）。源码及依赖对应源代码见 `PDFSandwich-0.4.2-source.zip`；校验值见 `SHA256SUMS.txt`。`latest.yml` 和 `.exe.blockmap` 供软件更新使用。

本次核对了本地问题页副本，并补充原创合成回归测试。复杂公式识别、翻译语义和自动词句对应仍可能有误差；验收范围见仓库 `docs/verification.md`。
