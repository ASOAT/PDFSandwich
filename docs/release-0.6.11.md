# PDFSandwich 0.6.11

改进双栏论文的翻译排版，避免正文引用编号被误识别为参考文献条目，导致正文与图注跨栏混排。

- 新增阅读信号轮盘：在 PDF 页内按住 **Alt 移动鼠标**，选择疑问、重点、赞同、灵感、绷不住或喜欢，松开 Alt 发送；左滑固定为问号；回到中心或按 Esc 取消。信号短暂显示，工具栏可关闭。
- 参考文献按完整源行重组，保留编号、分栏与悬挂缩进。
- 结构重组增加字形归属和区域边界检查；异常重组会回退到原始分段。
- 保留插图内部原文，修复部分旧式嵌入字体压缩后的显示错码。
- 更新页面翻译缓存版本，旧排版将随阅读重新生成，原始 PDF、批注和阅读位置保留。

在软件设置中检查更新，或下载 `PDFSandwich-Setup-0.6.11.exe`（Windows 10 / 11 x64）。
