# PDFSandwich 0.6.8

改进文献元数据检索、长标题笔记和公式排版。

- 更可靠地识别 PDF 首页标题与 DOI，减少页眉、无效内嵌标题和参考文献对检索的干扰。
- 增加 DataCite 与 OpenAlex，支持标识检索失败后按标题查找，并对结果排序、去重和补全缺失字段。
- 创建笔记保留完整标题，取消固定 110 字符截断；仅遇文件系统长度限制时缩短文件名，标题与正文仍完整保留。
- 改进公式上方符号与字母的组合保护，减少译文重排时的分离和错位。

在软件设置中检查更新，或下载 `PDFSandwich-Setup-0.6.8.exe`（Windows 10 / 11 x64）。已有模型、文献与笔记继续使用。
