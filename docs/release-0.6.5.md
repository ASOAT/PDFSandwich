# PDFSandwich 0.6.5

修复正文中的圆圈编号和交叉引用排版，并避免为中文或扫描 PDF 启动翻译服务。

- **圆圈编号**：白色数字与黑色矢量底图作为整体随中文正文重排，并按正确顺序绘制，避免只剩黑点、盖住文字或留在原位置。
- **引用与样式**：图号、公式号、表号和代码清单号作为完整引用处理，保留原编号及链接颜色。改进正文样式识别，减少公式两侧被拆成残句；保留独立的斜体和有色引用。
- **补译**：长段落校验失败时先按完整句子重试，最后才拆分公式两侧文字，减少缺失上下文造成的断句。自动翻译仍可能有语义偏差，请结合原文阅读。
- **导入检查**：中文文档、需要 OCR 的扫描件和无文字页不自动加载翻译服务。检查只读取文字层和图片信息，不下载模型、不运行 OCR。大文件使用有限页面抽样，未抽样页面在实际翻译前再次检查；已有有效 OCR 文字层的英文页面正常翻译。

更新后，已经缓存的译文请点击 **重译本页** 应用新的排版。原 PDF、批注、笔记和模型保留。

在软件设置中检查更新，或下载 `PDFSandwich-Setup-0.6.5.exe`（Windows 10 / 11 x64）。支持增量更新，无需重新下载翻译模型；已有 Obsidian Companion 可继续使用。
