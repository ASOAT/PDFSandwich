# 需求与验收草案

更新日期：2026-09-28。标注为“建议”或“待确认”的内容不视为用户已确认。

## 已确认

| 方面 | 需求 |
| --- | --- |
| 平台 | Windows 桌面软件 |
| 主要文档 | 英文教材、论文，约 1,000 页以内；文件体积上限待确定 |
| PDF 阅读 | 正常浏览、连续滚动、放大缩小 |
| 双语阅读 | 左侧英文原 PDF，右侧中文译文 PDF；两侧可驱动同步滚动 |
| 翻译范围 | 翻译文字，公式和图片不翻译；中文尽量保留原页码、版式和段落位置 |
| 文档识别 | 第一版按有文字层的 PDF 设计，不主动加入 OCR；扫描件需求暂不纳入 |
| 翻译时机 | 当前页和邻近页面优先，边阅读边翻译；可以后台翻译整本 |
| 翻译服务 | 可以用云端服务，也接受本地方案；具体供应商和模型待确定 |
| 编辑 | 高亮、下划线、手绘记号、批注；双向同步；批注文字保持原样 |
| 缓存 | 已翻译结果缓存在本机，再次打开继续使用 |
| 版本管理 | 使用 GitHub 管理项目 |

## 待确认

1. 文字标记跨语言对应的精度：对应句段、短语词语，还是仅同页坐标。
2. 导出范围及批注导出后的行为。
3. GitHub 仓库名称、公开或私有、项目发布及许可证选择。
4. 代表性文件的实际大小；性能验收机器和样本。
5. 云端服务配置或本地模型环境；真实翻译验收需要可用服务。

## 建议实现细节

- 阅读：页码跳转、目录、全文搜索、适合页宽、快捷键、恢复阅读位置。
- 同步：滚动以页码和页内位置为基准，避免两侧递归触发滚动；允许暂时解除同步。
- 编辑：所有标记具备稳定 ID，增删改及撤销重做作用于同一条共享记录。
- 手绘：采用页面坐标映射；文字高亮与下划线采用文本对应关系，具体精度待确认。
- 翻译：任务可取消、失败可重试；切页优先级可调整；网络请求及排版不阻塞阅读。
- 缓存：包含文件指纹、页码、源目标语言、引擎/模型和参数版本，避免错误复用。
- 原文件：默认保持原始 PDF，批注和翻译结果单独保存；导出写入新文件。
- 密钥：通过本机设置录入，不进入 Git，也不写入普通日志。
- 性能：仅渲染可见页和少量邻页；翻译分批执行，限制并发及缓存。

## 验收草案

以下为待实施、待验证的目标，不是已完成的能力。

1. 单栏、双栏论文及教材都可打开、缩放、复制文字和连续阅读。
2. 左右任一侧滚动后，另一侧到达对应页面和阅读位置；反复切页不会抖动。
3. 译文出现后仍可选取文字，公式与图片保持可读，页码对应关系不改变。
4. 两侧创建、修改和删除高亮、下划线、手绘及批注后，另一侧同步；重新打开后仍存在。
5. 翻译优先处理当前页，已缓存页面不重复调用翻译服务；失败显示错误并可重试。
6. 接近 1,000 页的样本可阅读，持续翻页时内存受控；测试记录文件大小、页数、机器、时间和峰值内存。
7. 导出功能、标记对应精度和性能数值门槛在相关需求确认后补全。

## 阶段

1. 需求确认、开源方案调研与版本管理。
2. 真实 PDF 阅读、双栏同步滚动和翻译引擎验证。
3. 双向标记、持久化、翻译队列、恢复与导出。
4. 大文件验证、Windows 打包、使用说明及 GitHub 发布。

每个阶段必须记录实际验证结果，不以静态界面或模拟译文代替真实功能验收。
