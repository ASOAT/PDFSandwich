# 已确认需求与实现边界

更新于 2026-09-30。

| 用户要求 | 当前实现 |
| --- | --- |
| Windows 软件 | Electron 桌面程序，Python 后端随安装包封装 |
| 英文教材/论文，1000 页以下 | 文字层 PDF；虚拟页面列表、范围读取、逐页翻译 |
| 正常阅读和缩放 | 连续滚动、缩放、目录、跳页、搜索、恢复阅读位置 |
| 左英文，右中文，左右滚轮同步 | 页码与页内比例双向联动，可解除同步 |
| 文字翻译，图片/公式不翻译 | BabelDOC 分析与重排；不启用 OCR；图注或矢量图内文字可能作为文字翻译 |
| 中文尽量保留原版式 | 沿用页尺寸、编号、公式原始字形，保留粗体/斜体/颜色；算法公式保留原坐标，编号参考文献逐条排版；复杂布局仍可能偏差 |
| 当前及附近页面优先，整本可排队 | 默认翻页插队，后台页在当前小段结束后让出位置，保留已加载模型和句段缓存；连续跳页以最后停留页为先，整本任务保留；主动暂停有效 |
| 不留整段英文漏译 | 长段落切分，质量检查失败时自动拆小补译、由程序保护公式；仍失败时仅保留相应片段并提示，旧版有警告的页会重译 |
| 高亮、下划线、手绘、批注双向同步 | 共享标记 ID，两侧独立几何；文字保持原样，支持撤销、重做、删除 |
| 标记精度尽量匹配 | 固定译文的本地 attention、术语与逐字坐标对应；失败不误划整段；可手动校正并保存；手绘和便笺按位置 |
| 直接保存原 PDF | Ctrl+S 写真实 PDF 批注；备份后原子替换，外部修改/数字签名/权限限制会阻止覆盖 |
| 本地免费开源优先 | 默认 HY-MT 1.5 1.8B Q4 + Vulkan；Argos CPU 负责对齐，也可单独用于轻量翻译；首次下载后可离线，无按量调用，HY-MT 受其社区许可约束 |
| 可配云端 API | 服务地址、模型、密钥可配置；本地模式不调用云端密钥 |
| 浅色和深色，认真设计界面 | 暖白/浅绿与石墨/玉绿两套主题；深色 PDF 黑底白字显示，保存文件不变；删除无意义口号 |
| GitHub 公开发布 | 经用户确认改为公开，AGPL-3.0-only；GitHub Release 提供安装包和对应源码，GitHub Pages 提供介绍页；数据/密钥/模型忽略 |

## 不属于当前版本的能力

OCR、正文文字编辑、任意语言互译、可靠的词级语义对齐保证、跨页翻译上下文、密码解密、签名 PDF 修改。
原有其他类型的 PDF 批注会保留，但自定义阅读覆盖层只显示上述四类标记。

## 验收口径

真实翻译与真实文件保存必须实测，不用静态模拟界面替代。大文件结果记录文件体积和页数，
单个合成样本的通过不代表所有教材可保持同等速度。具体已执行结果见验收记录。
