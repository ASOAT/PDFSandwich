# PDFSandwich 0.6.12

表情轮盘支持自定义：点击阅读工具栏“互动信号”右侧的设置按钮，为六个方向选择内置图标、Emoji 或本地图片，并修改名称与信号颜色。

- 上传 PNG、JPG、WebP 或 GIF，拖动、缩放和裁剪后生成 256 × 256 PNG 表情；保留透明背景，GIF 使用静态首帧。
- 编辑结果点击“保存轮盘”后生效，支持取消、单个方向恢复默认和全部恢复默认。
- 自定义表情保存在本机用户配置中，重启及更新后保留；图片不会上传，也不会写入 PDF。
- 保持按住 Alt 移动鼠标、松开 Alt 发送的操作方式，默认左侧仍为问号。

在软件设置中检查更新，或下载 `PDFSandwich-Setup-0.6.12.exe`（Windows 10 / 11 x64）。
