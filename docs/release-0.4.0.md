# PDFSandwich 0.4.0

增加应用内增量更新，并修复长段落标记同步、支持跨页选择。

- 启动后自动检查正式版，也可在“翻译与应用设置 → 软件更新”手动检查；自动检查可关闭。
- 下载优先复用现有安装包，只传输变化部分，显示下载进度并支持取消与重试。增量不可用时自动回退完整下载。
- 下载后校验完整文件，点击“重启并安装”才会开始安装；普通退出不会自动安装。
- 安装前处理未保存批注，保存失败或选择取消会停止更新。完成后恢复原文档和阅读位置，保留设置、模型、译文及批注草稿。

## 长段落与跨页标记

- 修复整段选区跨越多条翻译记录时中文侧不出现的问题，完整句子可直接对应，不依赖逐词注意力结果。
- 合并重叠范围，避免同一行重复高亮或下划线；已有标记显示也会去重。
- 两侧均支持跨页拖选，按页保存，整次选择可一次撤销/重做；中间页不需要全部加载到屏幕上。
- 英文侧未翻译页面的标记在译文生成后补上；中文侧跨页范围需已完成翻译。无法可靠对应的片段仍需手动校正。
- 打开旧文档时重新尝试旧版自动对应，保留手动校正。

## 从旧版升级

**0.3.x 及更早版本需要手动安装一次本版本。** 先保存批注并退出旧程序，再运行 `PDFSandwich-Setup-0.4.0.exe`。后续版本可直接在软件内更新。

## 下载

- `PDFSandwich-Setup-0.4.0.exe`：Windows 10 / 11 x64 安装包。
- `PDFSandwich-0.4.0-source.zip`：完整项目、构建脚本和所封装 AGPL 依赖的对应源代码。
- `SHA256SUMS.txt`：下载文件校验值。
- `latest.yml` 与 `.exe.blockmap`：供软件自动更新使用，无需手动下载。

真实安装包差分传输、缺失缓存回退、损坏文件拒绝、安装前保存/取消、深浅主题与重启恢复均纳入测试。具体结果见仓库 `docs/verification.md`。差分体积随改动变化，不保证每个版本都能节省相同流量。

软件及增量更新免费。当前安装包未签名；更新通过 HTTPS 获取并校验 SHA-512。翻译、排版和批注自动对应仍可能有误差，不支持扫描件 OCR 或修改原文正文。
