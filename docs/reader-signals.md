# 阅读信号轮盘

目标：在阅读区域提供短暂的本地情绪反馈，复用现有 React、Lucide 图标与主题，不增加运行时依赖，也不改变 PDF 批注数据。

交互参考：[radial-menu-js](https://github.com/axln/radial-menu-js) 的径向布局，以及 Electron 项目 [Kando](https://github.com/kando-menu/kando) 的拖动方向选择。这里只借鉴交互机制，未复制项目代码或游戏素材。

## 状态与边界

`空闲 → 鼠标位于已渲染 PDF 内，按下 Alt → 选择方向 → 松开 Alt 发送 → 2.2 秒清除`。

- 疑问固定朝左，松开 Alt 后在初始鼠标位置弹出金色问号。以按下 Alt 时的鼠标坐标为方向原点，36 px 内为取消区，六个方向各占 60°。轮盘显示位置可避开窗口边缘，方向计算仍使用原点。
- Esc、失焦、滚动、缩放和切换文档均取消；不在页面内启动，不处理触屏、右键及 AltGr / Ctrl+Alt。
- 捕获 PointerEvent 及其兼容鼠标事件，避免 Reader 的 `mouseup` 或手绘处理器创建多余批注。只在手势存续期间及释放后的短暂窗口拦截。
- 最多显示六个短暂信号；定时器在结束、取消与卸载时回收。遵循减少动态效果的系统偏好，支持屏幕阅读器状态通知。
- 启用偏好保存在 localStorage；没有服务端请求、持久化信号、声音或额外模型。

## 验证

`node scripts/signals-ui.mjs` 在隔离配置目录与原创示例 PDF 上运行真实 Electron 鼠标事件。覆盖六方向、取消、禁用、过期、滚动、失焦、明暗主题，以及所有批注与截图工具的兼容性；检查源 PDF 字节和批注数量未被信号修改。

## 自定义表情（0.6.12）

轮盘方向固定为六个，配置与手势分离。默认数据由 `electron/signal-defaults.json` 共享；编辑器按需加载，支持内置图标、Emoji 与本地图片，草稿取消不落盘。图片通过浏览器原生 ImageBitmap / Canvas 裁剪，PNG / JPEG / WebP / GIF 统一为 256 × 256 PNG，透明通道保留，GIF 仅取首帧。没有新增图片处理依赖或模型。

主进程再次验证六方向结构、名称、颜色、图片头部尺寸和真实解码结果；拒绝远程 URL、SVG、损坏文件与超限数据。配置集中保存在用户目录 `reader-signals.json`，同目录临时文件与原子替换确保失败不会覆盖原配置。图片嵌入配置，替换或恢复默认后无闲置附件；不进入逐页文档状态或翻译缓存。

验证分两层：Node 检查非法数据及写入失败保护；真实 Electron 测试覆盖上传、透明裁剪、配置取消、Alt 发送、应用重启恢复和恢复默认后的图片数据清理。
