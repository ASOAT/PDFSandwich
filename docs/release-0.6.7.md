# PDFSandwich 0.6.7

改善双栏阅读布局与复杂页面的翻译稳定性。

- 原文与译文向中间靠拢，缩小时保持紧凑间距，把多余空白留在外侧。
- PDF 配笔记的单页布局保持居中，继续支持鼠标位置缩放与双向同步滚动。
- 修复复杂绘图状态导致的翻译中断，以及部分斜体段落字号异常缩小的问题。

在软件设置中检查更新，或下载 `PDFSandwich-Setup-0.6.7.exe`（Windows 10 / 11 x64）。已有翻译模型与笔记继续使用。
