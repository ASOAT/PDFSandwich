# PDFSandwich 0.6.13

更新时可以看到准备、安装和重启的进度。

- 软件内显示保存笔记、保存批注、停止翻译、写入译文与阅读位置、关闭后台服务的完成状态。
- 安装时显示 Windows 安装器的实际文件进度，完成后自动重新启动，不必再点击完成。
- 重启时显示启动与文档恢复状态，随后返回上次阅读的 PDF。
- 保存取消或失败时保留已下载的更新，可处理后重试。

从旧版升级到此版本即可看到安装器的进度窗口；软件内的分步准备界面从此版本起提供。

在软件设置中检查更新，或下载 `PDFSandwich-Setup-0.6.13.exe`（Windows 10 / 11 x64）。
