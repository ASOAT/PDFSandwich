# PDFSandwich 0.3.0

Windows 中英对照 PDF 阅读器。本次修复公式与参考文献排版、双向标记同步，并首次公开发布源码。

## 更新

- 公式保留原始字形、上下标与括号关系；算法区公式、分数和行号保持原坐标，文字单独翻译。
- 译文保留正文加粗、斜体与颜色；章节编号独立保留，避免把“5 Experimental Results”翻成“5 个实验结果”。
- 编号参考文献按条目恢复间距与缩进，只翻译能可靠识别的标题，作者及出版信息保留原文。
- 修复公式、字体切换导致的高亮/下划线未能显示在另一侧的问题；重译后从英文选区恢复对应位置，避免相邻行文字干扰。便笺内容共用同一记录。
- 深色模式下两侧 PDF 同时黑底白字显示；批注颜色保留，保存和导出的 PDF 不受显示主题影响。
- 删除阅读界面无意义口号；保留当前页优先翻译、双向滚动、清晰缩放及原文件备份保存。

## 下载与升级

- `PDFSandwich-Setup-0.3.0.exe`：Windows 10 / 11 x64 安装程序，不需要另装 Python 或 Node.js。当前安装包未签名。
- `SHA256SUMS.txt`：安装包、源码和示例的 SHA-256 校验值。
- `PDFSandwich-0.3.0-source.zip`：完整项目、构建脚本与所封装 AGPL 依赖的对应源代码。
- `PDFSandwich-demo.pdf`：可用于体验的原创示例。

升级前保存批注并退出旧程序，再运行安装包。现有模型无需重复下载；本次排版更新会让旧译文在阅读时重新生成，批注草稿继续保留。

首次本地翻译需下载约 1.1 GB HY-MT 模型及运行时、排版资源、对齐模型。下载后可离线使用，不按量收费。本地模式不会调用云端密钥。

## 验证与边界

完成真实论文样本的公式、算法、章节编号和参考文献渲染检查；双向高亮/下划线、重译恢复、批注文字共享、原 PDF 保存重开及深浅色显示均纳入实测。详细结果见仓库的 `docs/verification.md`。

复杂 PDF 排版与自动词句对应仍可能存在偏差，无法可靠匹配时可手动校正；模型翻译不保证语义完全正确。暂不支持 OCR、改写原文正文或跨页翻译上下文。深色显示会改变图片的屏幕颜色表现。
