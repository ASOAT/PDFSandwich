# PDFSandwich 0.6.6

改进翻页翻译响应、首次资源下载和扫描版 PDF 显示，减少运行及安装占用。

- 翻到新页面时优先处理当前页，可中断旧页生成并复用已加载的模型；按阅读方向预先翻译后续页面。
- 译文显示不再等待整页词语对齐，标记时按需计算对应关系。
- 模型下载支持并行分段、断点续传和完整性校验；已下载模型继续复用。
- 为承接句提供相邻段落语境，改善公式后 `where` 等引导语的翻译。
- 修复带可选中文字层的扫描页中译文被底图遮挡的问题，以及公式提取中 `for all` 等短语的空格。
- 合并滚动记录写入、清理生成过程中的重复译文，移除未使用的视频处理组件。

更新不会重新下载已有模型。安装仍需短暂退出软件并替换程序文件；首次词语标记可能需要准备对齐模型。

在软件设置中检查更新，或下载 `PDFSandwich-Setup-0.6.6.exe`（Windows 10 / 11 x64）。
