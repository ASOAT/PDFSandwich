# PDFSandwich 0.5.0

新增文献库与中文 PDF 自动保存。

- 三栏文献库：分类、子分类、多个标签、标题/作者/年份/备注编辑、搜索、排序，以及批量添加分类和标签。
- 导入时复制到统一文献库，默认放在软件文件夹下的“文献库”。同名文件分别存放，重复导入同一路径复用已有条目；初始文件保持不变。
- 设置新增“自动保存中文 PDF”，默认关闭。开启后，译文随页面完成和批注变化逐步更新到库内原 PDF 旁的 `.zh.pdf`，未翻译页保留英文。
- 译文保存会保护已有同名文件和外部修改；失败时可重试或另存副本。软件更新、普通卸载均保留软件文件夹中的文献库。
- 旧版最近阅读记录在首次打开时复制入库，继承可复用的草稿和翻译缓存。可随时切换文献库与阅读视图。
- 新增维护者旧构建清理工具，默认预览，执行时保留当前版本、正在运行的程序和包含 PDF/文献库的目录。

**默认位置：安装文件夹\文献库。每份文献的原文副本和中文译文位于同一子文件夹。Ctrl+S 写入库内原文副本，初始导入文件保持不变。**

0.4.0 及以后的版本可在“翻译与应用设置 → 软件更新”下载并安装。增量可用时仅下载变化部分，否则自动下载完整包。也可下载 `PDFSandwich-Setup-0.5.0.exe`（Windows 10 / 11 x64）。

源码和依赖对应源代码见 `PDFSandwich-0.5.0-source.zip`；校验值见 `SHA256SUMS.txt`。安装包未签名；`.exe.blockmap` 和 `latest.yml` 供应用内更新使用。

当前文献库提供本地 PDF 分类与标签管理，不包含 DOI 检索、引文格式生成或云端同步。已有文献的存储位置暂不支持一键迁移。
